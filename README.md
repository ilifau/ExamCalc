# ExamCalc

ExamCalc ist ein einfaches ILIAS-Plugin, das einen wissenschaftlichen Taschenrechner im Testkontext bereitstellt.

## Features
- Rechner-Overlay direkt im Test
- Wissenschaftlicher Modus (Trigonometrie, Wurzeln, Potenzen, etc.)
- Automatische Aktivierung bei `showQuestion` im Test

## Installation
1. Plugin-Verzeichnis nach `Customizing/global/plugins/Services/UIComponent/UserInterfaceHook/ExamCalc/` kopieren
2. In der Plugin-Verwaltung installieren
